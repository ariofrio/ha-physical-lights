# Model provenance and limitations

The [original measurement CSV](original-measurements.csv) was exported from Andres Riofrio's LM-3000 observations of a Philips WiZ A23 21 W bulb, label `9290034999`, white mode only. The [rated product](https://www.usa.lighting.philips.com/consumer/p/smart-led-bulb-21w-eq150w-a23-e26/046677578718) specifies 2550 lm and 2200–6500 K. The published lumen value does not specify an anchoring CCT and is **not** an input to this model.

The measurement series held the phone approximately 3 inches from the bulb surface inside one circular shade. A session-specific lamp-off reading was subtracted before computing each lamp-only reading. The [reconciled records](grouped-measurements.csv) identify the ambient subtraction and repeated references. Five dimming knots at 6500 K define the shared relative-output curve: D=10, 25, 50, 75, 100 → 3.64%, 13.96%, 44.75%, 78.46%, 100%. Six peak knots define CCT dependence: 2200, 3009, 4003, 5011, 6006, 6500 K → 12,301, 20,201, 35,701, 23,901, 19,901, 18,301 lx inside the shade. Both are shape-preserving cubic interpolations; the production [JSON coefficients](../../custom_components/physical_lights/calibrated/a23_curve.json) came from the offline SciPy PCHIP fit. They describe **commanded** CCT, which can differ from measured emitted CCT at low brightness.

The reference at the bed was 198 lx with the lamp at 4001 K/100% minus 25 lx with it off, or 173 lx lamp-only. At 4001 K/50%, 103 minus 25 = 78 lx; the independent curve predicts about 77.4 lx. This single check supports the scaling at that setting and position, not uniform accuracy across all CCTs or all positions.

The model assumes that the bulb's normalized dimming curve is approximately shared across CCTs and that the shade/room transfer at the target position is linear and independent of CCT. Actual observations show modest dimming-curve differences between 2200, 4000, and 6500 K; the output is an estimate, not a calibrated lux meter. A different bulb of the same retail model or a different shade needs its own reference reading. A different CCT may change the room-transfer ratio, and daylight changes can contaminate off/on calibration. The source's native brightness is quantized to integer percentage steps and floored at 10% on; off is a separate state.

The [Home Assistant WiZ implementation](https://github.com/home-assistant/core/blob/2026.9.3/homeassistant/components/wiz/light.py) forwards its 1–255 brightness parameter to pywizlight, which [rounds to percent](https://github.com/sbidy/pywizlight/blob/v0.6.3/pywizlight/utils.py#L9-L16). The proxy selects the closest supported integer dimming step and reports estimated actual lx using the source's later HA state. Its estimate is unavailable when the source cannot report a white-mode brightness and CCT.
